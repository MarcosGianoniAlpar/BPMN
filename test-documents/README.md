# Documentos de teste

Coloque aqui as atas e descricoes de processo reais usadas para testar a
extracao. Estes arquivos **nao sao versionados** (ver `.gitignore`) porque
costumam ser confidenciais — apenas este README e o exemplo publico ficam no
repositorio.

## Baseline

Guarde, ao lado de cada documento, o ProcessSpec que voce considera **correto**
(revisado a mao) em `evaluations/expected/`. Isso vira o conjunto de avaliacao:
comparar a saida da LLM com o esperado da a metrica que mais importa —
"quanto o especialista precisou corrigir?".
